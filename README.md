## ⚙️ Getting Started

### Prerequisites

Make sure you have the following installed:

* Node.js
* npm / yarn / pnpm
* Git

### Installation

Clone the repository:

```bash
git clone https://github.com/your-username/your-portfolio.git
```

Navigate to the project directory:

```bash
cd your-portfolio
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open the local development URL shown in your terminal to view the portfolio.

## 🔧 Environment Variables

If the project uses environment variables, create a `.env.local` file in the root directory:

```env
NEXT_PUBLIC_EXAMPLE_VARIABLE=your_value
```

Do not commit sensitive credentials or private API keys to the repository.

## 📦 Production Build

To create a production build:

```bash
npm run build
```

To run the production build locally:

```bash
npm run start
```

## ☁️ Deployment

This project is deployed using **Vercel**.

The deployment workflow is connected to the GitHub repository, allowing changes pushed to the configured branch to be automatically built and deployed.

Typical workflow:

```text

      Git

       ↓
     Vercel
       ↓
Production
```
