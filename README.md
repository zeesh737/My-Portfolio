# Personal Portfolio

A modern, responsive personal portfolio website showcasing my professional experience, technical expertise, selected projects, and development work.

The portfolio is built with a focus on **performance, accessibility, responsive design, clean architecture, and maintainable code**.

## 🚀 Live Website

**[[View Portfolio]]([url](https://zeesh-development-phi.vercel.app/))**

## 🛠️ Tech Stack

* **Frontend:** HTML
* **Language:** TypeScript / JavaScript
* **Styling:** CSS
* **Deployment:** Vercel
* **Version Control:** Git & GitHub

## ☁️ Deployment

This project is deployed using **Vercel**.

The deployment workflow is connected to the GitHub repository, allowing changes pushed to the configured branch to be automatically built and deployed.

Typical workflow:

```text
Local Development
       ↓
      Git
       ↓
    GitHub
       ↓
     Vercel
       ↓
Production
```
